# Рабочие области (Project Workspaces)

Область группирует проекты и хранит их общий контекст. Этот контекст BB
автоматически вшивает в инструкции агента **только** для проектов области — в
другие проекты он не попадает.

Если текущий проект состоит в области, агент уже получил её контекст в
инструкциях (или указание вызвать инструмент `workspace_context`). Прочитать
полный контекст текущей области можно так:

```bash
bb workspaces context
```

## Команды

```bash
bb workspaces list                              # список областей
bb workspaces show <id>                         # одна область целиком
bb workspaces context                           # контекст области текущего проекта
bb workspaces projects <id>                     # проекты области
bb workspaces projects <id> --add <project-id>  # добавить проект (повторяемый)
bb workspaces projects <id> --remove <project-id>
bb workspaces create <id> <name> \
  --description "..." --instructions "..."
bb workspaces set <id> \
  --name "..." --description "..." --instructions "..."
bb workspaces remove <id> --yes
```

- `<id>` области — латиница в нижнем регистре, цифры и одиночные дефисы
  (например `mpstats`).
- `<project-id>` — идентификатор проекта BB вида `proj_...`; смотри
  `bb project list`.
- `--instructions` принимает длинный текст; длинную строку можно передать через
  `--instructions-stdin` (до 16 КиБ из stdin) или отредактировать в панели
  «Workspaces» в сайдбаре.
- Ограничения: имя ≤ 120 символов, описание ≤ 2000, общий контекст ≤ 64000.
- Области хранятся в хранилище плагина; команды работают на сервере BB.

## Правила

- Общий контекст области — это данные для работы (адреса, доступы,
  договорённости), а не инструкции общего назначения. Не клади сюда то, что
  должно действовать во всех проектах (для этого есть `~/.bb/AGENTS.md`).
- Если контекст области длинный, агент получает короткую ссылку и должен сам
  вызвать `workspace_context` или `bb workspaces context`, чтобы прочитать его
  целиком.
- Не меняй состав областей и их контекст без явной просьбы пользователя.
